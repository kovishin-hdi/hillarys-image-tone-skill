# Hillarys Image Tone Skill

This project contains a Claude skill for color grading and editing raw images to match the Hillarys Curtains & Blinds brand aesthetic.

## Skill

- `.claude/skills/hillarys-image-tone.md` — Complete image tone specification including:
  - Color profile parameters (warmth, saturation, contrast, shadow lift, etc.)
  - Sharp.js programmatic parameters (Node.js)
  - AI prompt templates for image editing models
  - Lightroom/manual editing slider values
  - Batch processing guidelines for different image categories
